# Alarma

Es una replica de la alarma (Samsung) con fines academicos, en el puedes establecer una alarma en el momento que desees y este se activara una vez que llegue el tiempo de la alarma establecida, puedes agregar mas de una alarma

## 🛠️ Tecnologías Utilizadas

- **Frontend:** 
  - HTML5
  - CSS
  - Javascript

## ✨ Características Principales

- Cuenta con la opcion de elegir el tono de alarma que mas te agrade.
- Puedes establecer un tiempo y cuantas veces quieras aplazar una alarma.
- Cuenta con la opcion para agregarle vibraciones al dispositivo una vez que se active la alarma.
- Puedes Eliminar O Desactivar una alarma agregada.
- Te muestra cuanto tiempo falta para la alarma mas cercana.
- Se adapta al tema establecida en el navegador.
